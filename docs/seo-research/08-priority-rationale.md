# Приоритет кластеров и Gate A

Дата решения: **2026-08-07**  
Рынок: **Россия**  
Статус: **Gate A пройден для трёх страниц с ограничением качества SERP-среза**.

## Решение

В первую волну включены:

1. `/website-support-chat/` — чат поддержки для сайта, **97/100**;
2. `/ai-support-bot/` — ИИ-бот поддержки, **81/100**;
3. `/support-sla/` — управление SLA поддержки, **80/100**.

Ни одна из страниц не создаётся как набор синонимов главной. У каждой есть отдельный job-to-be-done, подтверждённый runtime-контур и собственный ожидаемый формат выдачи.

## Данные, использованные в Gate A

- продуктовые утверждения и запреты: `00-product-search-brief.md`;
- поисковый baseline: `01-search-baseline.md`;
- 70 seed-фраз: `02-seed-queries.csv`;
- одномоментный анонимный срез 12 запросов × 2 поисковика × TOP-5: `03-serp-snapshots-partial.csv`;
- черновой реестр 18 доменов: `04-competitor-register-draft.csv`;
- аудит 15 ранжирующихся продуктовых/смежных конкурентов и их публичных URL: `05-competitor-analysis.md`;
- Wordstat: `wordstat-frequency-snapshot.csv`, регион Россия для приоритетных запросов, период 2026-07-07—2026-08-05 (для низкочастотных фраз 2026-07-06—2026-08-06).

Google Search Console не был доступен в авторизованном виде; Яндекс Вебмастер ещё не накопил запросы и показывает 0 страниц в поиске. Эти отсутствующие данные не заменялись нулями при scoring.

## Формула

```text
Priority = 20 × (
  demand × 0.25 +
  business_value × 0.25 +
  commercial_intent × 0.20 +
  product_evidence × 0.15 +
  serp_feasibility × 0.15
) + penalties
```

Каждая базовая оценка — от 0 до 5. Подробные значения записаны в `07-cluster-page-map.csv`.

## Почему выбраны эти три страницы

### 1. Чат поддержки для сайта — 97/100

Подтверждённый спрос:

- `чат для сайта`: 3432 broad и 129 phrase по России;
- `онлайн чат для сайта`: 199 broad и 52 phrase;
- `виджет чата для сайта`: 39 broad и 3 phrase;
- более узкий `чат поддержки для сайта`: 158 broad и 4 phrase по всем регионам.

Выдача содержит отдельные feature/solution landings ChatApp, Ростелекома, Teletype, Webim и Umnico, а также comparison pages. Это показывает отдельный solution intent. В Support Communication подтверждены Web SDK, сообщения, файлы, presence, polling ответов, приглашения и CSAT. Страница обязана честно указать, что для подключения нужны SDK key, разрешённый домен и настройка.

Content gap: показать не абстрактный «виджет», а сквозной путь `посетитель → диалог → очередь → оператор → оценка`, связав канал сайта с маршрутизацией и контролем качества.

### 2. ИИ-бот поддержки — 81/100

Подтверждённый спрос:

- `ии бот поддержки`: 340 broad и 17 phrase по России;
- `чат бот для поддержки клиентов`: 60 broad и 0 phrase.

SERP преимущественно информационный: Jivo, AutoFAQ, HelpDeskEddy и другие ранжируют guides; присутствуют solution pages. Поэтому страница должна одновременно отвечать на вопросы внедрения и показывать конкретный продуктовый workflow: источник знаний, версия сценария, sandbox/test run, публикация и handoff оператору.

Content gap: вместо обещания «автоматизировать всё» явно объяснить границы — ответ зависит от активного сценария, модели, лимитов и качества источников; неизвестный или сложный диалог передаётся человеку.

### 3. Управление SLA поддержки — 80/100

Подтверждённый спрос:

- `контроль SLA`: 242 broad и 36 phrase по России.

TOP-5 Яндекса и Google почти полностью состоит из guides и словарей. Чистая рекламная страница не соответствует intent. Поэтому выбран гибридный формат solution/guide: коротко объяснить, что контролируется, затем показать workload, назначения, перераспределение, паузу SLA и rescue просроченных обращений.

Content gap: соединить понятное объяснение SLA с реальным операционным сценарием руководителя смены. Запрещены обещания конкретного сокращения времени ответа или договорного SLA продукта.

## Что не прошло Gate A

| Кластер | Итог | Решение |
| --- | ---: | --- |
| автоматизация клиентской поддержки | 68 | объединить с `/ai-support-bot/`, не создавать синонимичную страницу |
| омниканальная поддержка | 60 | оставить главной; вернуться после live-gate внешних каналов и новых данных |
| helpdesk для бизнеса | 59 | оставить главной; штраф −15 за каннибализацию |
| система поддержки клиентов | 55 | оставить главной; точный Wordstat равен 0, штраф −15 |
| система учёта обращений | 50 | отложить: broad частотность загрязнена обращениями граждан |
| распределение обращений | 49 | часть intent включить в SLA-page; самостоятельную страницу отложить |
| API службы поддержки | 48 | оставить существующему `/docs/`, штраф −15 за каннибализацию |
| единое окно поддержки | 32 | reject: 9 из 10 результатов не относятся к B2B helpdesk |
| поддержка клиентов Telegram | 27 | переформулировать запрос: 10 из 10 результатов — поддержка самого Telegram |

## Проверка условий Gate A

| Условие | Website chat | AI bot | SLA |
| --- | --- | --- | --- |
| Priority ≥ 65 | да | да | да |
| Отдельный intent и URL | да | да | да |
| Функция и CTA подтверждены | да | да, с условиями | да |
| Каннибализация решена | да | automation merged | distribution merged частично |
| Содержательный gap | сквозной Web SDK workflow | sandbox→publish→handoff | guide + operational workflow |
| Оригинальные доказательства | SDK/API и продуктовый сценарий | сценарии, знания, test run | workload, assignments, rescue |

## Ограничение решения

План предусматривал 25–40 запросов × TOP-10 и повтор по Москве/Санкт-Петербургу. Доступный воспроизводимый срез содержит 12 запросов × TOP-5 для России. Расширение не подменялось веб-поиском без точной позиции и региона. Поэтому решение достаточно для первой малой волны, но не для масштабирования десятков URL.

Через 7 дней нужно повторить расширенный SERP-срез. Если новый срез показывает другой intent или сильную каннибализацию, metadata и ownership корректируются до второй волны; уже опубликованные страницы не размножаются под синонимы.
